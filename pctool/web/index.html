1Lift

Turn one photo, or several photos of the same place, into metric 3D points. You can also drop files on the viewport.

2Grow

Lift an image first.

  1. Fly to a view the points don't cover yet.
  2. 1280×720 PNG, transparent where there are no points
  3. Generate an image for that view with any image model, using the guide.
  4. Lifted with the viewport's field of view and placed at the viewport camera.
The camera moved since you saved the guide.
3Plan the path

Lift an image first.

Fly to a view and add it as a keyframe (K). Select a keyframe to move or rotate it with the gizmo.

4Export

Add a keyframe in step 3 to export a path.
